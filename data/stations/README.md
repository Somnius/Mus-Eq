# Station seed lists

- `trayfm-stations.txt`: Greek (and a few international) radio stations, copied unchanged from `stations-default.txt` in https://github.com/Constantinos/Tray-FM by Constantinos (Linux-user.gr). Released under the Unlicense (public domain). Format: `Name|Category|URL`, categories Music / News / Sports. A leading `# ...` line is a comment. Stream URLs have not been checked for liveness.
