# Decisions log (date, choice, reason). Open items live in `OPEN_QUESTIONS.md`.

- 2026-11-06 **Server in Rust**; Android client in Kotlin. Fits the owner, cross-compiles to Linux/Windows/macOS and Android, and the reusable part of cliamp (a Go terminal player) is only subprocess glue.
- 2026-11-06 **cliamp is an optional existing client, not a base.** Its station and yt-dlp logic is a reference (MIT notice if copied). A cliamp provider for MusEq is a phase 4 nice-to-have, not an exit criterion.
- 2026-11-06 **Greek radio list: Tray-FM** by Constantinos (Unlicense), copied to `data/stations/trayfm-stations.txt`. Stream liveness is checked in phase 2.
- 2026-11-06 **No WorkOS / hosted auth.** Token auth.
- 2026-11-07 **Auth: one owner bearer token from phase 1** (applies the Q9 default); `/v1/health` open.
- 2026-11-07 **Network: bind localhost by default, LAN/Tailscale is the owner's network** (applies the Q11 default).
- 2026-11-07 **External stations are passed through, never proxied.** `/v1/radio` is for library and live stations.
- 2026-11-07 **One `job` table** (kinds scan|fetch|tag|fingerprint) instead of separate job tables.
- 2026-11-07 **Transcoding: ffmpeg in the image; in-process Opus is an option measured at the start of phase 5.**
- 2026-11-07 **Phase 1 is split**: 1a server core (curl-checkable, CI green), 1b Webamp client and session, then phase 2.
- 2026-11-07 **Desktop shell stays open (Q13)**, browser first; decided at phase 4.
- 2026-11-07 **Phase 1a data shortcuts:** `artist`/`album` are text columns on `track`, one track per file, ids are SQLite integers exposed as strings, codec = file extension. Proper tables and fingerprints arrive with dedupe (phase 3).
- 2026-11-07 **Playlist edits:** items are removed/reordered by replacing the whole list (`PUT /v1/playlists/{id}/items`).
- 2026-11-07 **Server refuses to start without a token** (min 16 characters); it never prints it.
- 2026-11-07 **Browser auth is a cookie** (HttpOnly, SameSite=Strict) next to the bearer token, because `<audio>`, skin URLs and the WebSocket can't send headers. CSRF guard on cookie-authenticated mutations; WebSocket Origin check.
- 2026-11-07 **Session = the playing client reports, commands go to it.** Avoids every open tab starting playback.
- 2026-11-07 **Skins are stored raw and parsed in the browser**; the server never unzips them.
- 2026-11-07 **No read-only token yet**; widgets use the owner token. Revisit when per-device tokens arrive.
- 2026-11-07 **Web client is served by the server** (same origin); Vite proxies in development.
- 2026-11-07 **Process: each phase ends with tests, two independent reviews, doc updates and the owner's green light; commits are local per step and pushes happen at phase completion.**
- 2026-11-07 **Cookie = random server-side session id**, not the token (review finding): logout revokes it; login attempts are rate limited.
- 2026-11-07 **A moved or renamed file keeps its row** (matched by sha256 when its old path is gone), so playlists don't lose it.
- 2026-11-07 **Web client uses Webamp's private `__onStateChange` hook** to notice state changes. If a Webamp upgrade removes it, session reporting stops (the 10 s interval report still fires). Pin the Webamp version and re-run the smoke test on upgrades.
- 2026-11-07 **Logo:** three chunky equalizer bars (tall-short-tall, an M) with peak caps; segmented LED version for the README (assets/logo.svg), solid-bar version for the favicon (assets/favicon.svg). Hand-written SVG, no text or external assets.
- 2026-11-07 **Projects we can't copy (no licence, GPL, AGPL, incompatible) are re-implemented, not copied:** we learn their behaviour from docs, public APIs and use, write our own behaviour notes, and build our own Rust version from those notes. Public specs (OpenSubsonic, MusicBrainz, AcoustID) can be implemented directly. MIT/Apache/Unlicense code may be used with its notice. Ideas borrowed are credited here. See `docs/COMPARISON.md`.
- 2026-11-07 **Stations play in the browser through a plain audio element, straight from the station** (Webamp's loader needs CORS, which most streams lack). Plain-HTTP streams are blocked on HTTPS pages, so the Play button is disabled there with a note.
